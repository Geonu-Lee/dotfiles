# 개인 전역 지침

프로젝트와 무관하게 모든 세션에 적용.
(코딩 규율 — 단순화·수술적 변경·가정 명시·목표 기반 실행 — 은 `karpathy-guidelines` 스킬이 담당하므로 여기선 중복하지 않는다.)

## 🔴 항상
- **언어**: 답변·설명·주석은 한국어. 코드 식별자와 기술 용어는 영어로 유지.
- **추측 금지**: 모호하면 진행하지 말고 멈춰서 질문한다.
- **커밋·PR**: 명시적으로 요청받기 전에는 커밋/PR을 만들지 않는다(**자동 커밋 금지** — 지시 전까진). 만들지 여부를 **묻지도 않는다.** 내가 직접 커밋하지 않는다.
- **커밋에 Claude 흔적 금지**: 요청받아 커밋 메시지·PR 본문을 작성할 때 `Co-Authored-By: Claude ...`, "Generated with Claude Code" 등 Claude 관련 기록을 **절대 넣지 않는다.** 순수 변경 내용만.
- **검증 후 주장**: "완료·수정됨·통과"는 실제 실행/테스트 결과로 확인한 뒤에만 말한다.

## 🟡 선호
- 과장·마케팅 표현 금지. 트레이드오프를 솔직하게 말한다.
- 기존 코드의 패턴·네이밍·구조를 우선 따른다.
